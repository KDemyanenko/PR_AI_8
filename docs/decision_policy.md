# Правила довіри до результату та участі людини

Компонент C4 використовує випадковий ліс для оцінки класу високої загрози. `threat_score` — оцінка для класу 1, `confidence = max(p(0), p(1))`; ця впевненість **не відкалібрована** та не є відсотком гарантії правильності.

| Результат | Дія C5/C7 | Людина |
|---|---|---|
| `confidence ≥ 0.80`, усі входи коректні | Можна застосувати DP-07: відступ лише при `retreat_allowed` і (`HP ≤ 25` або `threat_score ≥ 0.85`) | Моніторинг результатів, без погодження кожної дії |
| `0.65 ≤ confidence < 0.80` | **Не використовувати оцінку ML** для DP-07; застосувати правило HP і дозволу | Створити запис на **асинхронний** огляд QA |
| `confidence < 0.65` | Не використовувати оцінку ML; fallback за HP | QA аналізує повторні випадки та помилки |
| Модель недоступна | Fallback за достовірного HP і `retreat_allowed` | Помилка до журналу C8/D4 |
| Відсутні координати/HP, значення поза межами | Безпечна зупинка; **не** виконувати нову автоматичну дію | QA отримує діагностичний запис |
| Дія заборонена C7 | Заборонити відступ незалежно від оцінки ML | Змінити правила може лише розробник |

Пороги **0.65 і 0.80** походять із ПР-7: на 100 синтетичних тестових записах для впевненості `≥ 0.80` отримано 66/66 правильних класифікацій, у проміжку 0.65–0.80 — 15/16, нижче 0.65 — 10/18. Ці частки стосуються **лише** тестового набору і не означають гарантій.

Коли ШІ недоступний, працює правило `HP ≤ 25%`, якщо втеча дозволена. Якщо бракує критичних даних, персонаж не повинен починати новий неперевірений маневр. ШІ не обирає маршрут: DP-08/DP-09 спроєктовані як окремі перевірки C5/C6/C7.
